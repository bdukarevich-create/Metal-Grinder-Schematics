# Metal-Grinder-Schematics
Schematics on paper from a metal grinder I made. 
This contains the manual schematics I made for my metal grinder. What this metal grinder does essentially is use an overclocked 4mm DC motor stuck to a 400 MaH battery. I mostly made it for deburring CNC machined rounds, and this one works quite well on 6061 aerospace aluminum.
